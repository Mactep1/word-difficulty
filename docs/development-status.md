## 真实端到端样例

使用项目自建的文本与字幕，未引用第三方书籍内容：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m word_difficulty analyze examples/demo.txt -o output --model
.\.venv\Scripts\python.exe -X utf8 -m word_difficulty analyze examples/demo.srt -o output --model
```

| 指标 | demo.txt | demo.srt |
| --- | ---: | ---: |
| 识别到的词语出现次数 | 80 | 18 |
| 词表判定的出现次数 | 68 | 15 |
| 模型判定的出现次数 | 11 | 3 |
| 专有名词出现次数 | 1 | 0 |
| 普通词汇聚合条数（含 A1/A2） | 58 | 18 |
| 默认 B1+ 导出条数 | 27 | 7 |
| 重复运行时的模型缓存命中次数 | 11 | 3 |
| 推理失败上下文数 | 0 | 0 |

示例输出位于 `output/demo.txt.*` 与 `output/demo.srt.*`。旧的 `output/demo.*` 是早期调试产物，不作为当前样例结果。输出保留源扩展名，避免不同格式同名文件互相覆盖。

上述数值证明处理流程正常，不代表难度标签具有人工核验的正确性。示例包含自造词 `zephyrium`；模型也可能对这类词给出高概率等级，因此概率阈值不能独立解决拼写错误或伪词识别。

本机服务的 `/_stcore/health` 已返回 HTTP 200。Streamlit 界面测试验证了示例载入、开始分析、结果展示和等级筛选；未将自动化测试误写为人工视觉验收。
